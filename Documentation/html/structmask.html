Detailed Description

Type used to represent a mask.

Remarks
The cells are indexed by integers ranging from 0 to hsize*vsize-1. They are ordered line by line from Top to Bottom. The cell of index 0 is at the Top-Left corner. The cells ranging from 0 to hsize-1 constitute the first line at the top of the grid, the cells ranging from hsize to 2*hsize-1 constitute the second line, and so on.
Attention
We always assume that a mask contains at least one non-masked cell (this property must be checked when reading a mask file).
