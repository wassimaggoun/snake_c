Detailed Description

Strategy functions for the AIs.

These are the functions used to determine the moves of the ai controlled snakes. A strategy function takes as input the game and the index of the snake to modify. It chooses the direction that the snake will use to exit the current cell and assigns this direction to the "move" field of the snake.

Attention
A snake cannot exit a cell by going back to the cell it came from. Hence, the strategy function must choose among at most three directions (the fourth unavailable direction is the one that the snake came from).
Remarks
You have to write the strategy functions. On the other hand, you should NOT call them yourself. Indeed, the strategy are called in the game loop which is already written. Each turn of the game loop consists of the following four steps:
  1. Use a generation function to generate new objects (the function is chosen when creating the game).
  2. Update the moving directions of player controlled snakes according to keyboard inputs.
  3. Apply strategy function to update the moving directions of the AI controlled (the functions are chosen when creating the game).
  4. Implement the turn for all snakes by calling the "implement_turn_all_snakes" function.

Enumeration Type Documentation

◆ strat

enum strat

Internal names of the available strategy.

In order to add a new strategy function, you must add a new internal name for this strategy, at the end of the list (before STRAT_SIZE). Then you must complete the three following steps: 1) Write the strategy function. 2) Add the function's name at the end of the strategy_funs array in project_objgen.c (this array contains all strategy functions). 3) Add a string describing the strategy at the end of the strategy_names array in project_objgen.c (this string will be displayed in the interface).
