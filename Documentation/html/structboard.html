Detailed Description

The type used to represent a board.

A board is a rectangular grid of cells. The cells of the board are indexed linearly line by line, from left to right and from top to bottom. If the board has hsize columns and vsize rows, the first cell (in the top-left corner) has index 0, the cell to its right has index 1, and so on. The last cell (in the bottom-right corner) has index (hsize * vsize - 1).

Each cell in the board can be masked (i.e., it cannot be occupied by snakes or objects). Masked cells are indicated by the masked array. If the cell with index i is masked, then masked[i] is true; otherwise, masked[i] is false.

The board also contains an array of objects that indicate the content of each unmasked cell. For each i, objects[i] is the object contained in the cell with index i. The object can be EMPTY (this special value indicates that the cell is empty), SNAKE (this special value indicates that the cell is occupied by some snake section), or one of the other objects defined in the object enum. If the cell with index i is masked, then objects[i] is undefined (its value is irrelevant).

The board also contains two arrays of directions that indicate the directions the snakes used to enter and exit the cells. For each i, if the cell with index i contains a snake section (as indicated by objects[i]), then indirs[i] is the direction the snake used to enter the cell, and outdirs[i] is the direction the snake used to exit the cell. If the cell with index i does not contain a snake section, then indirs[i] and outdirs[i] are undefined (their values are irrelevant).

Finally, the board also maintains a list of empty cells for quick access (they are the unmasked cells of index i where objects[i] is EMPTY). The empty_cells_count variable indicates the number of empty cells. All the empty cells are listed in the empty_cells_listing array at indices 0, 1, 2, ..., empty_cells_count - 1 in an arbitrary order (the array itself is of size hsize * vsize). The empty_cells_indices array is indexed by the cells indices (0, 1, 2, ..., hsize * vsize - 1), for each i, if the cell with index i is empty, then empty_cells_indices[i] is the index of the cell in the empty_cells_listing array that contains i; otherwise, empty_cells_indices[i] is -1.
