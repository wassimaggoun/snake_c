◆ object

enum object

Enum type used to represent all the objects that can be placed inside a cell of the board.

Remarks
The first object is EMPTY, which represents an empty cell. The second object is SNAKE, which represents a cell occupied by a snake section. The other objects represent the different types of food that can be placed in a cell for the snakes to pick up.

◆ swap_empty_cells()

void swap_empty_cells ( board * b,
int i1,
int i2 )

Swaps the positions of two empty cells in the array empty_cells_listing which lists the empty cells.

Remarks
This functions does not change the represented board. It only changes the order in which the empty cells are listed. This is sometimes in order to modify the empty_cells_listing array. For instance, removing a cell from the list of empty cells is done by swapping the cell with the last cell of the array and then decrementing empty_cells_count.
Parameters
bThe board.
i1The index of the first cell in empty_cells_listing.
i2The index of the second cell in empty_cells_listing.

◆ fill_cell_board()

void fill_cell_board ( board * b,
int i,
object obj )

Fills a cell of the board with an object.

If the cell already contains an object, the function does nothing. If the cell was empty, the cell needs to be removed from the list of empty cells. In this case, empty_cells_count, the empty_cells_listing array, and the empty_cells_indices array need to be updated accordingly.

Remarks
The function raises an error if the object is EMPTY (one cannot fill a cell with an empty object as it serves to indicate an empty cell).
Parameters
bThe board.
iThe index of the cell.
objThe object.

◆ empty_cell_board()

void empty_cell_board ( board * b,
int i )

Empties a cell of the board.

If the cell was empty, the function does nothing. If the cell contained an object, the cell is emptied in the objects array of the board. The cell needs to be added to the list of empty cells. In this case, empty_cells_count, the empty_cells_listing array, and the empty_cells_indices array need to be updated accordingly.

Parameters
bThe board.
iThe index of the cell.
