Detailed Description

Parameters.

Macros for the following parameters:

  • Activation of some debugging features.
  • Dimensions of the window.
  • Default parameters for the games. These are the parameters used if a quick game is launched.

◆ WINDOW_SCREENWIDTH

#define WINDOW_SCREENWIDTH   1820

Removes the onscreen message when pausing the game. Uncomment to activate.

If this macro is defined, the onscreen message that appears when the game is paused will be removed. This gives a better look at the game board for debugging purposes.

Activates debugging fo snakes. Uncomment to activate.

If this macro is defined, the cells that are marked as filled with a snake will be highlighted in white in the application.

Activates first debugging for the empty cells. Uncomment to activate.

If this macro is defined, the cells that listed as empty in the empty_cell_listing array will be highlighted in yellow in the application.

Activates second debugging for the empty cells. Uncomment to activate.

If this macro is defined, the cells marked as as empty in the empty_cell_indices array will be highlighted in blue in the application.

Activates debugging for the masks. Uncomment to activate.

If this macro is defined, the selected mask will be displayed on the terminal (by calling the function print_mask which you have to write) before the game is launched.

Horizontal dimension of the application in pixels (default = 1820).
