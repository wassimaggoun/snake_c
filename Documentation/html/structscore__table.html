Detailed Description

Type used to represent the scores of each game in a series of games.

In the interface, it is possible to create a series of several consecutive games. This type is used to store the scores of each snake in each game of the series as well as the final scores of each snake (the sum of the scores of the snake in each game).

The array of scores is a two-dimensional array of size nb_snakes x (nb_games + 1). If i is the index of a snake (in the socre table) and j < nb_game is the index of a game, then scores[i][j] contains a pointer to the score of the snake i in the game j (which are filled after this game is played). Also, scores[i][nb_game] contains a pointer to the final score of the snake i: the sum of the scores of the snake in each game (which is filled after all the games are played).

Remarks
The snakes are not necessarily stored in the same order as in the game (this is because it is possible to sort score tables according to one of the scores types). The correspondence with the indices of the snakes in the game is given by the game_to_score and score_to_game arrays.
