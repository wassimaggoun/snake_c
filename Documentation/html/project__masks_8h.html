Resizing a mask.

Conversion of a mask whose dimensions are arbitrary to give it the desired dimensions.

Attention
The mask must be resized to the new dimensions. The number of masked cells must be updated. At least one cell must be unmasked.

◆ read_mask()

mask * read_mask ( const char * path)

Generation of a mask from a file.

Attention
The file must contain an ASCII representation of the grid:
  • The character X corresponds to a masked cell.
  • Any other character indicates an unmasked cell.
Remarks
Examples of such files are given in the "Masks" directory.
Attention
The file must contain a perfect rectangle (all lines must have the same length). The mask must contain at least one unmasked cell. If the file does not meet these conditions, the function returns NULL.
Returns
The mask read in the file.
Parameters
pathString containing the path to the file.
