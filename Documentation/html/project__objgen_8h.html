Detailed Description

Objects generators.

These are the functions used to generate new objects on the board. An object generator function takes as input the game and fills its board with one or more objects.

In order to generate random numbers, you can use the "int rand();" function from the standard library. This function returns a pseudo-random number in the range [0, RAND_MAX]. You can use the modulo operator to get a random number in a specific range. For example, to get a random number in the range [0, 9], you can use the following code: "rand() % 10".

Remarks
You have to write the generator functions. On the other hand, you should NOT call them yourself. Indeed, the strategy are called in the game loop which is already written. Each turn of the game loop consists of the following four steps:
  1. Use a generation function to generate new objects (the function is chosen when creating the game).
  2. Update the moving directions of player controlled snakes according to keyboard inputs.
  3. Apply strategy function to update the moving directions of the AI controlled (the functions are chosen when creating the game).
  4. Implement the turn for all snakes by calling the "implement_turn_all_snakes" function.

Enumeration Type Documentation

◆ generator

enum generator

Internal names of the available object generators.

In order to add a new generator, you must add a new name here, at the end before OGEN_SIZE. Then you must complete the three following steps:

  • Write the corresponding generator function.
  • Add the function at the end of the generator_funs array in project_objgen.c (it contains all generators functions).
  • Add the name at the end of the generator_names array in project_objgen.c (it contains all generators names). This is used to display the generator name in the interface.

◆ gen_ten_percent()

void gen_ten_percent ( game * g)

Ten percent generator.

Ensures that exactly ten percent of the empty cells are always filled with random objects. If the percentage of filled cells drops below ten percent, the generator fills randomly chosen empty cells with random objects until the percentage is ten percent.

Parameters
gThe board.

◆ gen_student_invasion()

void gen_student_invasion ( game * g)

Invasion of the students generator.

Ensures that exactly twenty percent of the empty cells are always filled with students. If the percentage of filled cells drops below twenty percent, the generator fills randomly chosen empty cells with students until the percentage is twenty percent.

Attention
When eaten, students can increase the length of the snakes significantly. Before tou use this generator, make sure that the function used to consume food handles the error that may happen when the full length of the snake becomes "too high".
Parameters
gThe board.
