void sort_scores ( score_table * st,
int n_g,
score_type type )

Sorts the snakes in a score_table according to a particular type of score for a particular game of the series (or the the final score).

The array score in the score_table must be sorted in decreasing order of the score type given as a parameter.

Remarks
This function is called automatically by the interface.
Parameters
stThe score_table.
n_gThe game according to which the sort must be made (or nb_games for the final score).
typeThe score type according to which the sort must be made.
